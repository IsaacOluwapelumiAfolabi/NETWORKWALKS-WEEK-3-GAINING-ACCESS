# Week 3 – Key Learning Outcomes

During Week 3, I studied the Gaining Access stage of the cyberattack lifecycle, focusing on password cracking and password security.

## What I learned
- Password cracking is the process of attempting to recover a password from protected data or a password hash.
- Password hashes can be extracted from certain protected files for authorized password-recovery testing.
- John the Ripper can be used through a command-line workflow or a graphical interface such as Johnny.
- Password reuse increases the impact of a credential compromise.
- Strong, unique passwords and multi-factor authentication help reduce account compromise risk.

## Practical experience
- Used Online Hash Crack to extract a PDF hash.
- Used John the Ripper through Johnny GUI and observed a successful crack result.
- Used NetworkWalks Hash Calculator and Password Cracker to complete a second PDF password-recovery exercise.

## Responsible practice
All practical work was limited to the PDF supplied for the training exercise. Passwords, hashes, and challenge-specific flag strings should not be published in a public repository.
