# Project Module 2 – NetworkWalks Hash Calculator and Password Cracker

## Objective
Recover the password of the training-provided PDF using NetworkWalks' Hash Calculator and Password Cracker.

## Tools
- NetworkWalks Hash Calculator: https://networkwalks.com/hash-calculator/
- NetworkWalks Password Cracker: https://networkwalks.com/password-cracker/
- Windows laptop and web browser

## Methodology
1. Opened the NetworkWalks Hash Calculator in a web browser.
2. Uploaded the assigned PDF and extracted its hash.
3. Copied the extracted hash value.
4. Opened the NetworkWalks Password Cracker.
5. Pasted the hash into the tool and initiated the recovery attempt.
6. Completed the exercise and captured the platform's completion confirmations.

## Result
The password-recovery exercise was successfully completed. Screenshots show completion confirmations from the NetworkWalks training platform.

## Evidence
The screenshots in `Evidence/` show the training completion messages. The individual flag strings have been redacted because this is a public portfolio repository.

## Security note
Do not submit confidential documents or hashes to third-party websites unless you have permission and have assessed the service's data-handling practices. Use password-recovery tools only within an authorized scope.
